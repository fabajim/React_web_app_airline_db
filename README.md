# AirlineDB 

## Frontend Setup
### Run the following:
#### From the root directory
```bash
cd .\Frontend\
```
```bash
npm install
```
### To start frontend app:
```bash
npm run dev
```

## Backend Setup
#### From the root directory
```bash
cd .\Backend\
```
```bash
npm install
```
#### To run backend app:
```bash
npm start
```
